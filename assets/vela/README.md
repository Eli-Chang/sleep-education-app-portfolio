# Vela asset provenance

These SVGs are the canonical vector exports from the locked Figma file `APmrjWc2eVj82sEQTmkMVu`, node `2:289` (`Vela Sheet / mascot states`). They were downloaded through the Figma MCP asset flow on 2026-08-16.

- `vela-idle.svg` is the canonical saturated-purple Vela mark with exactly two open eyes and no mouth.
- `vela-blink.svg` is the canonical Vela mark with the two closed-eye rectangles used for the idle blink state.

The implementation does not redraw the mascot or add an orange backplate. Figma asset URLs are temporary and are intentionally not used at runtime.
