# Security

- Do not add patient data, research data, credentials, tokens, cookies, private documents, or institutional assets.
- Keep lesson content synthetic and visibly labeled as demonstration content.
- Preserve the explicit consent gate before any teach-back request.
- Keep provider credentials and remote configuration outside the client and outside this repository.
- Treat knowledge-check and teach-back output as demonstration behavior, not clinical guidance.
- Report suspected issues privately to the repository owner before public disclosure.
