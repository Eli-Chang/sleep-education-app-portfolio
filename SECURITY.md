# Security

Do not commit `.env`, `.env.local`, `.dev.vars`, provider keys, signing secrets, deployment credentials, private evaluation artifacts, patient data, or learner identifiers.

The optional AI Worker is a demonstration boundary. Before any real deployment, add authenticated operational controls, secret rotation, rate limiting, abuse monitoring, privacy review, dependency review, and a documented incident response process.

To report a security issue, open a private GitHub security report if enabled for the repository. Do not post credentials or sensitive data in a public issue.
