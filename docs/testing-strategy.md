# Testing Strategy

- Strict TypeScript checks validate the content and state contracts.
- Domain tests cover bilingual parity, synthetic labels, notice presence, navigation, immutable progress, progress restoration, narration cues, knowledge checks, consent gating, bounded input, successful delegation, and failure fallback.
- Playwright checks cover the desktop and mobile static demonstrations, console output, and visible organization-neutral disclaimer text.
- A production build would add device-level navigation, screen-reader, dynamic-type, offline, narration, and visual regression checks.
- Professional language, accessibility, safety, and clinical review remain human gates.
