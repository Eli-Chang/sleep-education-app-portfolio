# Image sources and public-asset boundary

This repository includes only image assets whose reuse basis is clear from the recorded attribution.

| Asset family | Attribution / license |
| --- | --- |
| `cpap-open-airway.svg` | Michael Brenner / Wikimedia Commons, public domain |
| `cpap-patient.png` | MyUpchar / Wikimedia Commons, CC BY-SA 4.0 |
| OpenMoji illustrations | OpenMoji, CC BY-SA 4.0 |

Six source-derived Module 1 image files were intentionally withheld because their local notes did not provide independently verified reuse permission. The app therefore degrades to text and other attributed visuals for those lessons. This is a publication decision, not a claim that the withheld files are public domain.

When adding an asset, record its creator, source URL, license, required attribution, and the exact file path before including it in the public build.
