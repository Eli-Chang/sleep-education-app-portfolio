# Privacy and Safety Decisions

- The public lesson module is synthetic and visibly labeled.
- No patient data, research data, private documents, credentials, account identifiers, or organization assets are present.
- Lesson content is bundled so basic navigation does not require a network.
- Teach-back requests require explicit consent, bounded learner text, and an injected requester.
- A requester failure returns a local fallback without blocking the lesson.
- This is a portfolio demonstration, not a clinical application or medical-advice source.
