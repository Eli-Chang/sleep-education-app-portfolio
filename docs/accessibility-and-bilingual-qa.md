# Accessibility and Bilingual QA

Stable module and screen identifiers are compared across English and Spanish so a translation cannot silently omit or reorder a lesson. Every screen must contain the exact notice for its locale.

The neutral preview uses readable contrast, visible status labels, responsive layout, and concise text. A production UI should additionally test dynamic type, screen-reader names, focus order, touch targets, reduced motion, keyboard navigation, and offline status messaging on supported devices.
